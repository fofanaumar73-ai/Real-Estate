## ✨ Features

The current demo includes:

- **Luxury design:** A sophisticated black-and-gold theme with an elegant visual style.
- **Responsive layout:** Designed to adapt to desktop, tablet, and mobile screens.
- **Animated loading screen:** A house-inspired animation introduces the website.
- **Interactive navigation:** Desktop navigation and a mobile-friendly menu.
- **Property showcase:** Visually appealing cards for displaying property listings.
- **Property search:** Filter demo properties by location, property type, and maximum price.
- **Property categories:** Browse different types of residences, including villas, apartments, penthouses, and estates.
- **Interactive animations:** Scroll reveals, subtle image effects, floating particles, and cursor interactions.
- **Favourites interaction:** Visitors can interact with property favourite buttons.
- **Testimonials section:** A dedicated area for showcasing client reviews.
- **Animated statistics:** A section for highlighting business achievements.
- **Enquiry form interface:** A form for collecting prospective buyers' requirements, ready for backend integration.
- **Contact section:** A clear call to action encouraging visitors to make enquiries.

These features currently form part of a frontend demonstration. Some interactions use sample data and are not connected to a live database or backend.

---

## 🛠️ Technology Stack

The website is built using:

- **HTML5** — Website structure and content.
- **CSS3** — Layout, responsive styling, animations, and visual effects.
- **JavaScript** — Interactive components, property filtering, loading animations, and user interface behaviour.

The current version is a frontend-only project. It does not require a database or backend server to display the demo.
